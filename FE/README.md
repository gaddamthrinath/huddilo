# Huddilo Frontend

Next.js frontend for Huddilo, a secure real-time meeting and collaboration platform.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

- `src/app` — routes, layouts, and global styles
- `src/components/brand` — reusable brand elements
- `src/components/layout` — shared page structure
- `src/components/meeting` — meeting-related UI

The meeting creation button is currently presentational. API integration will be added later.
